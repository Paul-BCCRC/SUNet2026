This assumes you have Anaconda/Spyder and Cuda/cudnn already setup.

Step 0: Open command prompt:
Start --> Anaconda3(64bit) --> Anaconda Prompt  (Right click run as admin)

Step 1:	Create pytorch environment.
When the prompt begins you should be in (base) C:\Windows\system32> base is the env you're working in.

Type "conda env list" to view all the environments setup.

Type "conda create -n pytorch" to create a new env "pytorch" which we will install all the modules into.

Next activate the env we just made "conda activate pytorch". You can type "conda list" to see all the modules installed in the active environment. 
With the pytorch env active install the following:

conda install python==3.12.3

conda install pytorch torchvision torchaudio pytorch-cuda=11.8 -c pytorch -c nvidia     
					Installs pytorch cuda 11.8
conda install scipy
conda install scikit-image
conda install openpyxl			For spreadsheet output
conda install tqdm			For progression bars
conda install matplotlib		For training plots
conda install -c conda-forge ome-types	For ome metadata

pip install imagecodecs

conda install spyder-kernels=2.4	Installs spyder kernel version 2.4

If this is the wrong version of spyder-kernel Spyder will tell you which version when you run something.
